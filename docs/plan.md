# CareerTrace AI — 키 없는 MVP 구현 계획

사용자가 제공한 PRD와 후속 요청(키 없이 개발)을 기준으로 한다.

## 설계와 범위
- React·TypeScript·Vite·Tailwind, FastAPI·SQLAlchemy·SQLite. 로컬 단일 사용자 앱.
- 실제 GitHub REST 조회와 SQLite 저장은 정상 동작한다. 인증·배포·결제는 범위 밖.
- 분석은 명시적인 `규칙 기반 데모` 엔진. OpenAI 호출이나 API 키 자동 사용 없음.
- 데모 샘플은 버튼으로만 불러오며 모든 파생 경험·초안에 샘플 표시를 유지한다.
- 사용자 확인은 사용자 진술 확인이며 외부 검증을 뜻하지 않는다. 근거 연결과 확인 상태를 분리한다.
- 저장소 활동을 개인 성과로 자동 귀속하지 않는다. 원문과 작성자를 보여주고 본인 행동을 직접 작성·확인한다.
- 추천은 키워드·역량 일치 기반이며 의미 검색·LLM 분석이 아님을 알린다.
- 초안은 사용자 확인한 STAR 문장을 조합한다. 초과 문장은 제외하고 편집 초과는 저장 거절한다.
- 초안 내용 편집 시 모든 자동 근거 연결 해제. 원본 자료는 별도로 열람 가능하며 새 문장에는 검증 완료 표시 없음.

## 구현 순서
1. `backend/tests/test_api.py`: 저장 지속성·미확인 차단·샘플 표시·근거 참조·문자 수·GitHub 오류 테스트.
2. `backend/app/{schemas,models,database,engine,github,main}.py`: 데이터와 API 구현.
3. `frontend/src/{App,components,pages,api,types}`: 대시보드, 경험 목록·입력·상세, GitHub, 매칭, 초안 편집.
4. 핵심 API 테스트, TypeScript 빌드, 실제 GitHub 조회, 브라우저 전체 사용자 흐름 검증.
5. `README.md`, `.env.example`, 실행 스크립트와 검증 결과 제공.

## 우선 검증할 실패 조건
- 잘못된 GitHub URL·비공개 저장소·호출 제한·네트워크 실패.
- 빈 경험·타인 활동·확인하지 않은 경험의 초안 생성.
- 빈 추천·글자 수가 너무 작은 문항·사용자 편집 후 근거 연결 변경.
- 재시작 후 기록 유지, 샘플과 실제 기록 혼동 방지.
- 근거 URL 안전성, 저장소 텍스트를 HTML/명령으로 실행하지 않기.

## 진행 기록
- 기존 파일 없음 확인. 신규 폴더 `outputs/careertrace` 사용.
- 사용자 키 없는 개발 승인. 실제 LLM 기능은 이번 산출물에 포함하지 않음.
- 저장·분석·추천·초안 API와 React UI 구현, 테스트 20개 및 빌드 통과.
- 실제 GitHub 조회와 샘플 경험→초안→편집→새로고침 흐름 브라우저 확인.
- 코드 리뷰 피드백 반영: 미저장 초안 이동 보호, 수정 시 역량 재추출, 작은 화면 메뉴 이름.
